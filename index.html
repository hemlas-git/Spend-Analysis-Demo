How it is built

A small pipeline of AI agents turns a mailbox into decisions. This page is the last step.

1. Read
Agent 1 searches Gmail (read-only) for bank, UPI, shopping and delivery alerts and writes one clean row per transaction.
2. Analyse
Agent 2 removes duplicates, pairs refunds with orders, sorts spend into 11 budget categories and finds subscriptions. Agent 2b adds the budget categories, and Agent 1b collects income.
3. Decide
Agent 3 builds this dashboard. The north-star metric is everyday spend per month, with six savings levers. Each category has a limit and a status.
4. Repeat
A scheduled task re-runs the whole pipeline every Monday. Personal data never leaves my machine and the cloud workspace, and this public copy uses generated data.

Built with Claude (agents, Gmail connector, scheduled tasks), Python, d3 and Vercel.
